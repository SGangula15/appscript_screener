# AutoSys Tech Solutions Website

Production-ready premium automotive engineering website built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, GSAP, Three.js, React Three Fiber, React Hook Form, Zod, Lucide-ready styling, and SEO metadata.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — lint checks

## Architecture

- `app/` — App Router pages, metadata, global styling
- `components/` — reusable UI, layout, and cinematic sections
- `constants/` — navigation, technologies, V-model stages, solution catalogs
- `lib/` — shared utilities

## Future-ready modules

The information architecture is prepared for authentication, a client portal, AI chatbot, appointment booking, resume upload, knowledge base, customer dashboard, and admin dashboard.
